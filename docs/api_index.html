Setup, checks and worked examples

  • qstab_check_installation: Read-only integrity and MATLAB resolution checks.
  • qstab_setup: Connect the public namespace and optional examples for this session.
  • run_qstab_public: One standalone acceptance run, without an external qeig.
  • test_qstab: Run the complete qstab regression and native integration suite.
  • export_qstab_paper_figures: Export SAVED data without recomputing solvers.
  • plot_qstab_paper_figure: Plot one SAVED item; never calls a numerical solver.
  • qstab_benchmark_assess: Check semantics and reconstruct a returned witness.
  • qstab_benchmark_cases: Deterministic scalar families, not new stability methods.
  • qstab_benchmark_plan: Explicit applicable/nonapplicable comparison rows.
  • qstab_benchmark_summarize: Preserve unresolved and failed observations.
  • qstab_demo: Small examples of quaternion nominal and robust stability.
  • qstab_demo_plots: Similarity-class plots and sampled norm-polynomial values.
  • qstab_eigen_assess: Independent reference/multiplicity and eigenpair checks.
  • qstab_eigen_cases: Deterministic matrices with known right-class multisets.
  • qstab_eigen_match: Bottleneck bijection of canonical complex multisets.
  • qstab_eigen_timing: Matched ONE-output batches, with retained call results.
  • qstab_guide_example: Run the small, checked examples printed in the public guide.
  • qstab_paper_cases: Selected source-linked examples; no solver calls or files.
  • qstab_paper_check: Assess a source reference without turning unknown into true.
  • qstab_paper_evaluate: Execute one catalogue item without writes or plotting.
  • qstab_paper_extension_cases: Sixteen additional source-linked finite checks.
  • qstab_paper_extension_evaluate: Additional finite identities and witnesses.
  • qstab_paper_figures: Ordinary data for eight selected article illustrations.
  • qstab_validate_paper_figure: Validate ordinary plotting data before side effects.
  • run_qb01_discrete: Selected analytic discrete one-quaternion margin examples.
  • run_qb01_examples: Selected exact examples from the corrected qB01 notes.
  • run_qb02_balls: Selected weighted-coefficient-ball examples, ordinary data only.
  • run_qb02_boxes: Component boxes, not coefficient balls or vertex-only tests.
  • run_qb02_extensions: qB02 reductions and correlated CT/DT zero-exclusion.
  • run_qb02_qb03_examples: Compact reproducible cases for qB02/qB03 methods.
  • run_qb03_four_generator_examples: Separate article-oriented qB03 demo.
  • run_qstab_benchmarks: Matched, bounded scalar robustness comparison.
  • run_qstab_diagnostics: Reproducible enclosure, coverage and witness examples.
  • run_qstab_eigen_comparison: Reference-backed, read-only right-spectrum study.
  • run_qstab_paper_extensions: Reproduce SELECTED source-linked qB01/qB02/qB03 examples.
  • run_qstab_papers: Reproduce SELECTED source-linked qB01/qB02/qB03 examples.
