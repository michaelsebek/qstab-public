## Help and calling sequences

```text
QSTAB_EIGEN_CASES Deterministic matrices with known right-class multisets.
Ordinary component structs; no random state, global variables or qeig call.
The reference comes from a diagonal/triangular matrix and, where stated,
an explicitly retained real similarity. It is not computed with eig.
```
