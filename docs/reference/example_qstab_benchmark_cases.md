## Help and calling sequences

```text
QSTAB_BENCHMARK_CASES Deterministic scalar families, not new stability methods.
Each entry stores the original public input, convention, reference status,
and a reason. Fixture construction is outside the timed solver calls.
References describe analytic properties of these specific inputs, not
guaranteed termination of a finite-budget numerical method.
```
