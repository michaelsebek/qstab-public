ZEROEXCLUDE Adaptive norm-value zero exclusion for scalar polynomial families.
  A qstab.family definition supplies its variable, grade and parameter model.
  [TF,Info] = qstab.zeroexclude(data,...)
  TF is a double: 1 strictly stable, 0 demonstrably not strictly stable
  (including a confirmed boundary member), NaN unresolved or prerequisites
  not met. Inspect Info.status to distinguish these cases; test isnan(TF)
  before using TF in a branch. Info retains the complete diagnostic report.
  Info is the full diagnostic structure returned by earlier releases.
 [~,R] = qstab.zeroexclude({L,U},'Uncertainty','interval','Variable','s')
 [~,R] = qstab.zeroexclude({P1,P2,...},'Uncertainty','polytope','Variable','s')
 [~,R] = qstab.zeroexclude({P1,P2,...},'Uncertainty','polytope','Variable','z')
 [~,R] = qstab.zeroexclude(...,'Variable','zinv')
 [~,R] = qstab.zeroexclude(V,'Reduction','four-generator')

 The optional qB03 four-generator reduction tests entire subfamilies
 generated by at most four input polynomials, NOT just vertices/edges.
 MaxCells and MaxTime are GLOBAL budgets across all subfamilies;
 MaxSubfamilies limits their number. The default Reduction='none' keeps
 the established subdivision. Both paths certify nonvanishing over the
 FULL leading-coefficient hull (after reversal for zinv).

 The scalar coefficients are ascending and supplied as ordinary MATLAB
 numeric/quaternion arrays, cells, or native component structs. No new
 classes are introduced. A reference member must be strictly stable.

 For HURWITZ INTERVALS, at each frequency interval the attainable even
 and odd quaternion evaluations are enclosed by separate R^4 boxes.
 At a FIXED frequency these boxes are EXACT for independent Cartesian
 coefficient intervals (qB02). Subdivision of the 8 real evaluation
 components plus frequency bounds the real and imaginary parts of
        N_p(i*w) = |e|^2-|o|^2 + 2i*real(e*conj(o)).
 If either real or imaginary range excludes zero, so does the norm image.

 For POLYTOPES, form B_ij(s) = sum_(nu=0)^3 p_i,nu(s)*p_j,nu(s).
 The exact norm image of convex combinations is enclosed by the convex
 hull of B_ij on each parameter simplex (qB03, degree-2 Bernstein).
 A derivative bound encloses controls over a whole frequency interval.
 Parameter hulls and frequency intervals are subdivided adaptively.
 This branch supports s, z, and zinv via coefficient reversal.

 Varying-leading polytopes use a full-hull supporting-hyperplane bound;
 the coefficients are NOT normalized separately. Joint affine parameter
 boxes and interval boxes in z/zinv use quadratic norm-image enclosures.
 Additional CT interval reductions: kharitonov-cube, kharitonov-faces
 (pair-free faces, at most 1024), and quadratic-faces (monic degree 2).

 Result STATUS: 'stable' (all frequency/parameter cells excluded zero),
 'notStable' (actual admissible nominal counterexample),
 'assumptionFailed' (known degree loss), or 'undetermined'. In particular,
 zero inside an OUTER Bernstein polygon is NOT a counterexample.
 No vertex-only stability claim is made.

 Floating-point enclosures include tolerance cushions but NOT directed
 rounding. Stable means a numerical sufficient-certificate computation,
 not a validated interval-arithmetic proof. If a cell is unresolved or a
 numerical bound overflows, the function does not claim stability.

 Uncertainty omitted or '' means infer the kind from DATA, as in
 qstab.familycomponents (a cell input defaults to a polytope).

 Options: Uncertainty, Variable, MaxCells (4096), MaxDepth (32),
          MaxTime (30 s), Tolerance (1e-10), StoreCertificates (false),
          Reduction (default 'none'), MaxSubfamilies (1024).

 See also qstab.robuststable, qstab.normpoly, qstab.valueset.

  Examples (ascending coefficients):
  [tf,R] = qstab.zeroexclude({[1 1],[2 1]},'StoreCertificates',true);
  disp(tf);

  Interpretation:
  A coarse outer hull containing zero is not a true zero. Complete cell coverage or a reconstructed admissible witness is needed. Budgets retain unresolved obligations. Reduction methods test continuous subfamilies.

  See also qstab.about.
