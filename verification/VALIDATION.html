Earlier exact failure and its correction

The failed rc.1 fixture has p0=s^2+s+1, p1=1, and radius sqrt(3)/2. Decimal input text could enter symbolic floating-point arithmetic before GCD and Sturm calculations. Rc.2 instead constructs decimal, scientific and fractional text from exact integers and powers of ten, requires exact symbolic rationals, and decides polynomial-zero identities by exact normalized numerators. No small-remainder tolerance replaces an exact zero test.

For this fixture, 0.8660 is exactly 433/500 and 0.8661 is exactly 8661/10000. The lower bound gives zero nonnegative roots of the relevant square-free factor and the upper bound gives two. The corrected native targeted suite passes this fixture and the added input/identity regression groups.

The rc.1 transcript summary retains its original failure. The rc.2 development record describes the auxiliary Octave/SymPy work completed before the native reports arrived; its then-pending native flag is historical and is superseded by the separate native evidence above. Its Java-dependent source-hash assertion failure remains recorded. The initial candidate evidence also remains unchanged. Those historical auxiliary computations are not MATLAB execution and are not counted as native passes.

Reproduce the current public distribution

From the extracted public package root in a fresh MATLAB session:

qstab_setup('Examples',true);
R = run_qstab_public('Figures',false);
assert(R.ok && R.publicAcceptance.ok,'Read the public report: %s',R.archiveFile)

T = test_qstab_oneparameter('ExactCertificates',true);
assert(T.ok && T.complete,'Read the exact report: %s',T.archiveFile)

A = run_qstab_oneparameter('all','Plots',true,'ExactCertificates',true);
assert(A.ok && A.articleComplete,'Read the article report: %s',A.archiveFile)

The last two calls require Symbolic Math Toolbox. Ordinary numerical calls do not acquire that dependency. Exact scope is continuous-time scalar rational component polynomials with fixed leading coefficient; the radius routine checks supplied bounds. This is not a general exact uncertain-matrix radius result. The earlier interval-article Symbolic replay is a separate path and its historical native-validation status is unchanged. See the article guide and installation/dependencies.

Reproduce on another installation

From the extracted, writable package directory in a fresh MATLAB session:

report = run_qstab_public('Figures',false);
disp(report.status)
disp(report.archiveFile)
assert(report.ok && report.publicAcceptance.ok, 'Read the public acceptance report.')

The archive, qstab_test_results.zip, contains report.mat and report.txt. Use Figures=true only to additionally export the publication figures. Report files from your own computer may contain installation paths. Numerical tests and plots exercise the implementation; they do not establish robust stability of an arbitrary new model.
