qstab · Quaternion Stability Toolbox for MATLAB

Version 0.20.0 · Read the illustrated guide · Function reference · Scalar one-parameter article · Interval article · Installation and dependencies

Test nominal and robust strict stability for scalar quaternionic polynomials; compute right spectra of quaternion state matrices and representatives of algebraic zero classes. Families may be polytopes, independent coefficient intervals, real affine families, or one constant quaternion acting from a specified side. Coefficient balls and component boxes, continuous and discrete tests, radii, witnesses, and sampled plots are included in this release. Robust polynomial matrices are outside the supported scope; the square polynomial-matrix companion is a nominal experimental feature.

Validation: native MATLAB R2024b Update 2 records identify the tested sources separately: the rc.1 transcript reports 748/748 ordinary public checks; the corrected rc.2 reports show 32/32 targeted checks and 13/13 article groups with 139/139 comparisons, including fresh exact proofs. All 221 recorded MATLAB source hashes match the delivered rc.2. The final 0.20.0 changes version/descriptive text, documentation and metadata; algorithms, examples and tests retain their rc.2 contents. A new native run of the renamed final distribution is not claimed. Validation and scope.

Reproduce the scalar one-parameter article

qstab_setup('Examples',true);
R = run_qstab_oneparameter('all','Plots',true,'ExactCertificates','auto');
R.status
R.articleComplete
R.archiveFile
assert(R.ok,'Inspect the saved report: %s',R.archiveFile)

This calculates E1–E7, the two additional tangency variants and directional diagnostics from manuscript revision 7. run_qstab_oneparameter('list') lists the keys; use 'E1' for one case. The automatic ZIP is qstab_oneparameter_results.zip at the package root. Optional Symbolic Math Toolbox enables fresh qstab.raycertificate and qstab.radiuscertificate proofs plus the 42 algebraic identities. An absent or skipped exact engine is explicit: R.ok can be true while R.articleComplete is false. No Python process is launched by MATLAB. See all commands, output locations and assumptions.

qstab.freqmargin now also describes the nearest-gain geometry and both evaluation-side zero witnesses. CT scalar margin calls record automatic or explicit frequency scaling; E7 can be supplied in its original units. The new exact ray enclosure is the first positive contact, including tangencies; the existing numerical ray output remains a signed stable interval.

Reproduce the interval article and supplement

qstab_setup('Examples',true);
R = run_qstab_intervals('all','Plots',true);
R.archiveFile
assert(R.ok,'Inspect the saved interval report: %s',R.archiveFile)

This runs the 24 source-linked groups from IJRCN_manuscript_v7 and IJRCN_Zenodo-supplement_v5. Use run_qstab_intervals('list') to see the key or run_qstab_intervals('I19','Plots',true) for the five-gain regulator. Each run retains actual results, separate reference values, comparison checks and diagnostics. The current-run ZIP is qstab_interval_results.zip beside the launcher. Native quaternion is the default; UseQuaternion=false explicitly selects ordinary component structs. The optional exact certificate replay is separate from numerical root checks; see instructions and scope.

First minute

Unzip to a new folder. Change the MATLAB current folder to the directory containing qstab_setup.m. Run:

qstab_setup('Examples',true);
F = qstab.family('polytope',{[1 1],[2 1]});    % p(s)=s+a, 1 <= a <= 2
[tf,info] = qstab.robuststable(F);
tf                                             % 1
info.status
R = qstab_guide_example('G06');                % one checked, headless example

Use tf==1, tf==0, and isnan(tf): the three results are strictly stable, demonstrably not strictly stable, and undecided or unmet assumptions. Open info.status for the distinction. For a robust failure also inspect its witness. Coefficients are ascending; [2 3 1] is 2+3s+s². Scalar roots are algebraic similarity classes: they need not vanish under point evaluation at the displayed representative.

qstab_guide_example() lists the keys; qstab_guide_example('all') executes all eleven in local function workspaces. The examples do not write files, download software or open figures. To make figures, use the explicit plot calls in the guide. To validate a full native installation separately, use report=run_qstab_public('Figures',false). That acceptance run writes qstab_test_results.zip beside the runner; it checks basic graphics even when optional figure export is disabled. Read the validation record.
